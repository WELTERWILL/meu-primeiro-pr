# meu-primeiro-pr

Repositório de teste para aprender o fluxo de Pull Requests no GitHub.

## Como contribuir

1. Crie uma branch a partir da `main`: `git checkout -b minha-melhoria`
2. Faça suas alterações e crie um commit: `git commit -am "Descreva a mudança"`
3. Envie a branch: `git push -u origin minha-melhoria`
4. Abra um Pull Request: `gh pr create`
